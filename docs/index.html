Scoreboard

A simple two-team scoreboard for iPhone and iPad. No ads, no tracking, no accounts.

How to use it

  • Tap or swipe up on a side to add a point. Swipe down to take one away.
  • The timer starts automatically. Use the play/pause button to stop and start it.
  • Open the menu (☰) to Reset scores and timer, or Switch sides.
